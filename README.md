# Sistem Perkembangan Akademik Digital Terintegrasi

Folder ini digunakan sebagai workspace utama untuk pengembangan frontend Next.js, skema database Supabase, dan script sinkronisasi Google Sheets (GAS).

## Struktur Folder yang Direncanakan:
- `/` - Root workspace Next.js.
- `/schema.sql` - Skema database Supabase.
- `/sync.js` - Kode sinkronisasi Google Apps Script.
- `/quran_mapping.js` - Peta nilai/angka ke surat & materi.
